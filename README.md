# BioClimateChamber
[Part of a university project] Gemeinsame  informationstechnische Betreuung und Weiterentwicklung eines Systems aus Sensorik, Regelung, Befeuchtung, Kühlung/Heizung, Lüftung, Steuerung und Application zum erreichen optimaler klimatischer Bedingungen für die Reifung, Gärung und Kultivierung von Lebensmitteln.
